# Cypher System for Foundry VTT - New Cypher Editon 
A personal development fork of [Cypher System for Foundry VTT](https://github.com/mrkwnzl/cyphersystem-foundryvtt), originally created and maintained by [mrkwnzl](https://github.com/mrkwnzl).

This repository contains modifications to align the Foundry Cypher system with the newly released [Cypher Character Rulebook](https://www.montecookgames.com/store/product/cypher-corebooks/).

It is at this point **not intended to replace the original project**. The upstream repository remains the authoritative version of the Cypher System for Foundry VTT.

When I create a change that I believe could benefit the wider Cypher System / Foundry VTT community, I intend to propose it to the original project following its contribution process, so it can be reviewed and potentially incorporated upstream.

For the official system, documentation, support, releases, and community development, please visit the [original repository](https://github.com/mrkwnzl/cyphersystem-foundryvtt).
